# expert-adventure

Project Description: View Employee Information and Data

This repository includes a lightweight employee dashboard that allows you to search for employees, filter by department or status, and review key employee details in a spreadsheet-style table.

## Features
- Search by name, email, role, department, or location
- Filter by department and employment status
- Review summary KPIs including total employees, active count, average salary, and remote workers
- Export the currently filtered employee list to a CSV file

## Run locally
1. Open `index.html` in any modern browser.
2. Use the search box and filters to find employee records.
3. Click "Export CSV" to download the current filtered list.

## Files
- `index.html` — dashboard layout
- `styles.css` — Excel-like styling and responsive layout
- `script.js` — employee dataset and filtering logic
